## Le Contexte Cosmologique

Le modèle ΛCDM attribue la dynamique observée des amas de galaxies à la matière noire (~25% de l'univers) et à l'énergie noire (~70%). La TMT propose que ces deux phénomènes soient des manifestations de la **distorsion temporelle quantique** dans les puits de potentiel — sans particules exotiques.

Dans les **amas de galaxies**, notre modèle prédit que l'expansion locale de l'espace est légèrement ralentie par rapport aux vides cosmiques :

```
H(z, ρ_amas) = H₀ × √[Ωm(1+z)³ + ΩΛ × (1 - β × (1 - ρ/ρ_c))]

Pour ρ_amas / ρ_c ~ 17.5 : H_amas / H_CMB = -0.57% (ralenti)
Pour ρ_vide  / ρ_c ~ 0.3  : H_vide  / H_CMB = +8.7% (accéléré)
```

Cette **expansion différentielle** pourrait laisser des signatures observables dans les propriétés des amas de galaxies — exactement le type d'environnement extrême que vous étudiez.

## Prédiction Testable sur les Amas

La TMT prédit que les **supernovae Ia** dans les amas de galaxies devraient paraître légèrement plus proches que celles dans les vides cosmiques :

```
Δμ(vide - amas) ≈ +0.57% en distance lumineuse
```

Nous avons testé cette prédiction avec les données Pantheon+ (1700 SNIa) :
- **Observé** : +0.46%
- **Prédit** : +0.57%
- **Ratio** : 0.80 ✓

Ce résultat est dans la bonne direction avec la bonne magnitude.
