## La Question Posée

Le modèle ΛCDM postule l'existence de matière noire non-baryonique pour expliquer les courbes de rotation plates observées. La TMT propose que cet effet soit une conséquence de la **superposition temporelle quantique** dans les puits de potentiel gravitationnel — sans particules exotiques.

La question centrale est : **la loi d'échelle k(M) et la relation r_c(M) que nous observons empiriquement ont-elles un fondement physique naturel dans une théorie de la distorsion temporelle ?**

## Formulation TMT v2.4

```
M_eff(r) = M_bary(r) × [1 + (r / r_c(M))^n]

r_c(M) = 2.6 × (M_bary / 10¹⁰ M☉)^0.56  kpc     [r = 0.768, p = 3×10⁻²¹]

k(M)   = 4.00 × (M_bary / 10¹⁰ M☉)^(-0.49)        [R² = 0.64, 172 galaxies]
```

## Lien avec vos Relations d'Échelle

Votre travail sur les relations d'échelle des galaxies spirales (Tully-Fisher, relations masse-vitesse) identifie un défi fondamental : la dispersion residuelle inexpliquée par les baryons seuls. La relation r_c(M) de la TMT offre une explication physique à cette dispersion :

- Les galaxies de **faible masse** ont un r_c petit → l'effet temporel est confiné au centre
- Les galaxies **massives** ont un r_c plus grand → l'effet temporel s'étend davantage
- Ce comportement reproduit naturellement les tendances observées dans vos catalogues
