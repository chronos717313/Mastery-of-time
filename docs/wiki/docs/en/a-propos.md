# About

> The historical name "Mastery of Time" reflects the project's informal
> name; the formal scientific designation is the
> **Temporon-Mediated Theory (TMT)**.

## The author

Pierre-Olivier Després Asselin is an independent researcher based in
Montréal, Québec. His work focuses on scalar-tensor extensions of general
relativity, with applications to galactic dynamics and cosmological
observations.

- **Affiliation**: Independent Researcher
- **Contact**: pierreolivierdespres@gmail.com

## This site

This site documents the development of the Temporon-Mediated Theory and
collects the associated reproducibility materials (data, code,
manuscripts). It is intended for a scientific readership. The reference
results are those of the manuscript submitted to *Physical Review D*;
earlier materials are kept as a development record.

For questions about the data or code, see the GitHub repository
[`chronos717313/Mastery-of-time`](https://github.com/chronos717313/Mastery-of-time).
