# Lettre — Prof. Claude Carignan
**Université de Montréal — Département de physique**
**Spécialité : Cinématique galactique, courbes de rotation**

---

Objet : Vérification indépendante d'un formalisme alternatif à la matière noire — données SPARC

---

Monsieur Carignan,

Je me permets de vous écrire directement parce que vos travaux sur la cinématique des galaxies naines et les courbes de rotation à faible brillance de surface représentent, à mes yeux, la référence la plus rigoureuse dans le domaine. Votre contribution aux données qui ont alimenté le catalogue SPARC — sur lequel je travaille depuis plusieurs mois — rend votre regard particulièrement précieux pour ce que je cherche à soumettre à l'épreuve.

Je développe, de façon indépendante, un formalisme que j'appelle la Théorie de Maîtrise du Temps (TMT). L'idée centrale est la suivante : la distorsion temporelle générée par le potentiel gravitationnel — une réalité de la relativité générale — contribue à la dynamique galactique via un terme de masse effective scalaire :

```
M_eff(r) = M_bary(r) × [1 + (r / r_c)^n]
```

où le rayon de transition r_c suit une loi empirique calibrée sur vos propres données :

```
r_c(M) = 2,6 × (M / 10¹⁰ M☉)^0,56 kpc     [r = 0,768, p = 3×10⁻²¹, 103 galaxies]
```

J'ai appliqué ce formalisme à l'ensemble des 175 galaxies du catalogue SPARC (Lelli, McGaugh & Schombert 2016). Le résultat — 156 galaxies applicables sur 156, amélioration médiane de 97,5 % du chi² par rapport à Newton seul — est suffisamment inattendu pour que je ne veuille pas le publier sans un regard extérieur sérieux.

**Ce que je vous demande** n'est pas une caution, mais une vérification critique : est-ce que la formulation est physiquement cohérente sur les cas que vous connaissez le mieux — DDO 154, NGC 3198, les galaxies LSB de votre catalogue ? Y a-t-il des galaxies que vous jugeriez particulièrement discriminantes pour tester ce type de formalisme ?
