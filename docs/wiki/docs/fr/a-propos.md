# À propos

> Le nom historique « Mastery of Time » correspond au nom informel du
> projet ; la désignation scientifique formelle est la
> **Temporon-Mediated Theory (TMT)**.

## L'auteur

Pierre-Olivier Després Asselin est un chercheur indépendant établi à
Montréal, Québec. Ses travaux portent sur les extensions
scalaire-tensorielles de la relativité générale, avec des applications à la
dynamique galactique et aux observations cosmologiques.

## Ce site

Ce site documente le développement de la Temporon-Mediated Theory et
rassemble les matériaux de reproductibilité associés (données, code,
manuscrits). Il est destiné à un lectorat scientifique. Les résultats de
référence sont ceux du manuscrit soumis à *Physical Review D* ; les
matériaux antérieurs sont conservés à titre d'historique.

Pour les questions relatives aux données ou au code, voir le dépôt GitHub
[`chronos717313/Mastery-of-time`](https://github.com/chronos717313/Mastery-of-time).
