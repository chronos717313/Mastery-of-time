## QUESTIONS FRÉQUENTES

**Q: Puis-je publier en français sur Zenodo?**
R: Oui! Mais recommandé d'avoir abstract en anglais pour visibilité internationale.

**Q: Zenodo est-il reconnu par la communauté scientifique?**
R: Oui, c'est une plateforme CERN officielle, indexée dans tous les moteurs (Google Scholar, OpenAIRE, BASE).

**Q: Puis-je supprimer ma publication?**
R: Non, les DOI sont permanents. Mais vous pouvez marquer comme "superseded by" et publier nouvelle version.

**Q: Combien de temps le DOI est-il valide?**
R: À vie. Zenodo garantit préservation 20+ ans minimum (financé par EU Horizon).

**Q: Puis-je ajouter coauteurs après?**
R: Non. Il faut republier nouvelle version avec tous les auteurs.
