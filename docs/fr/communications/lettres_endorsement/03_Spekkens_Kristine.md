## La Prédiction Clé pour le SKA

La TMT prédit que les raies spectrales HI (21 cm) dans les halos galactiques doivent exhiber un **décalage dépendant du rayon** lié à la distorsion temporelle locale :

```
Δλ/λ = (m_e c² / E_transition) × τ(r)

où τ(r) est la distorsion temporelle au rayon r
```

**Amplitude prédite** : Δλ/λ ~ 4% dans le halo de M31 entre r = 50 et 100 kpc

Ce signal serait **non-observable avec les télescopes actuels**, mais potentiellement accessible avec la résolution spectrale du SKA. Il constitue donc une prédiction distinctive qui peut **falsifier** la TMT : si le SKA ne détecte pas ce décalage radial, la théorie est réfutée.

## La Théorie en Bref

La TMT propose que la "matière noire" observée dans les courbes de rotation est une manifestation de la superposition quantique des états temporels de la matière :

```
|Ψ⟩ = α(r)|t⟩ + β(r)|t̄⟩

M_eff(r) = M_bary(r) × [1 + (r / r_c(M))^n]
```

où `r_c(M) = 2.6 × (M_bary / 10¹⁰ M☉)^0.56 kpc` est le rayon de transition,
empiriquement calibré sur les 175 galaxies SPARC (r = 0.768, p = 3×10⁻²¹).
